# Biophysical Origins of Life II

Static conference website starter for GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a local server from this directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Create a GitHub repository, such as `biophysical-origins-of-life-ii`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.

Replace the placeholder sections and the form behavior when registration and mailing-list services are selected.
